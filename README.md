# Zyaba-Focus

Zyaba-Focus - it's J2ME Emulator-wrapper, which GUI is written in Qt, and paired with FreeJ2ME-plus Java API, just install the ".jar", ".jam", ".jad" or ".kjx" file, and play ::)
